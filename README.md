# Starpath Property — Mobile-First App Prototype

A luxury mobile-first real-estate prototype for **Starpath Holdings Ltd.**

🌐 **Live Cloud Demo:** [https://starpath-property.surge.sh](https://starpath-property.surge.sh)

---

## 🌟 Features

- **Mobile-First Experience**: Optimized for 390 × 844 mobile viewport with responsive desktop device frame.
- **Starpath Brand Identity**: Integrated official Starpath logo, signature color scheme (`#0B1F3A` navy and red accents), and hotline integration (`09610969620`).
- **Featured Projects**:
  - **Peace Harbor** — Block D, Bashundhara R/A (2,400 sq. ft. · 4 Bed)
  - **Starpath Anukabbo** — Block B, Aftabnagar (1,740 sq. ft. · 3 Bed)
  - **Starpath Grand Residence** — Banani DOHS (3,600 sq. ft. · 4 Bed)
  - **Starpath Heights** & **Lake View** — Gulshan
  - **Starpath Gardenia** — Bashundhara Block I
  - **Starpath Urban Residence** — Uttara Sector 4
  - **Starpath Signature** — Dhanmondi 9/A
- **Dhaka Interactive Map**: Interactive property map with custom Starpath markers across Dhaka and bottom preview sheets.
- **Inquiry Capture**: Instant booking requests with reference ID generation and live lead logging.
- **Admin Management & Live Sync**: Real-time management portal to adjust available units (e.g., 7 → 6) with instant buyer-side synchronization.

---

## 🛠️ Tech Stack

- **React 19**
- **TypeScript**
- **Vite**
- **Tailwind CSS v4**
- **Lucide React Icons**
- **Leaflet & OpenStreetMap**

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/starpath-property.git
cd starpath-property

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
